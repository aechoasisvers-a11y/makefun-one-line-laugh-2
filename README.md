A single self-contained one-liner for the make.fun "One Line, One Laugh"
bounty: a smart fridge that judges its owner's midnight snacks, and the
owner's dignified response — eating in the dark like it's a heist.

`main.py` (pure stdlib Python 3.13) writes the line to
`/output/entry.txt` with no trailing newline, after checking the gate:
1–140 UTF-8 characters, not only whitespace.
